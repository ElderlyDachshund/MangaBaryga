# Repository Instructions

## Agent skills

### Issue tracker

This repo currently uses local Git only, with no remote issue tracker and no local markdown issue files. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five-role triage vocabulary for any proposed work states. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout: one root `CONTEXT.md` plus `docs/adr/` when those files exist. See `docs/agents/domain.md`.
