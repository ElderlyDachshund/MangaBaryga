# Проверка светлой разновидности ранга D — 2026-07-27

## Что измерял бот

К приложенному снимку есть чёрные поля, поэтому для проверки была выделена
оригинальная область карточки: `x=496`, `y=144`, `288 × 432` пикселя. Это
тот же размер и верхний левый участок, который анализирует бот для оригинала
карточки.

До изменения обычные признаки были нулевыми: все цветные пиксели рамки были
светлее прежнего предела `0.85`, поэтому результатом был `unknown`.

После добавления отдельного светлого спектра результат для этой рамки:

| Результат | Оттенок | Насыщенность | Светлота | Доля светлых цветных пикселей |
| --- | ---: | ---: | ---: | ---: |
| `D` | 0.582622 | 0.243015 | 0.914899 | 0.277019 |

Новая разновидность ограничена одновременно по всем четырём признакам:

- оттенок: `0.56–0.60`;
- насыщенность: `0.20–0.32`;
- светлота: `0.88–0.95`;
- доля пикселей: `0.22–0.36`.

Основные диапазоны существующих рангов и порядок их проверки не менялись.
