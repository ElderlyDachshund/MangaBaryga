# Issue Tracker

This repo currently uses local Git only. There is no configured remote issue tracker, and issues should not be written as local markdown files by default.

## Workflow

- Treat `git` branches, commits, and project documents as the source of truth for planned work.
- Do not create `.scratch/` issue files unless the user explicitly asks for local markdown issues.
- Do not call GitHub or GitLab issue commands unless a remote issue tracker is configured later.
- When a skill would normally create issues, present the proposed work items in chat or update an explicitly requested project document instead.
- If a remote such as GitHub or GitLab is added later, update this file before using issue-writing skills.

## Current status

- Repository type: local Git repo
- Remote issue tracker: none
- Local markdown issue tracker: not enabled
